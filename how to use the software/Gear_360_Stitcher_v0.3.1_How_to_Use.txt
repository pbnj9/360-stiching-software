GEAR 360 STITCHER v0.3.1 - HOW TO USE
========================================

WHAT THIS VERSION DOES
v0.3.1 keeps live stitched previews and Quick Stitch Controls. Its Start
stitching and Choose output buttons are always visible in the Source Files
toolbar, even on shorter screens.

OPEN THIS VERSION
OPTION A - WINDOWS APP
1. Open the `gear360-stitcher\dist` folder.
2. Double-click `Gear-360-Stitcher.exe`.
   Python is not needed to run the executable.

OPTION B - PYTHON SOURCE
1. Open PowerShell.
2. Run:
   cd "C:\Users\jacks\OneDrive\Desktop\360 stiching software\gear360-stitcher"
3. Install requirements once:
   python -m pip install -r requirements.txt
4. Start the app:
   python main.py

BUILD THE WINDOWS APP
1. Open PowerShell in the current `gear360-stitcher` folder.
2. Run:
   .\build-exe.ps1
3. The executable is created at `dist\Gear-360-Stitcher.exe`.

STITCH PHOTOS OR VIDEOS
1. Open Stitch Photos or Stitch Videos.
2. Select Add photos or Add videos and choose raw Gear 360 files.
3. Select Choose output in the Source Files toolbar and choose the destination.
4. Adjust Quick Stitch Controls if needed.
5. Select Start stitching in the same toolbar.
6. The Live Stitch Preview shows stitched output as processing continues.

PREVIEW UPDATES
- Photos: the preview updates after each image is stitched.
- Videos: the preview updates for the first frame, about once per second, and
  the final frame.

QUICK STITCH CONTROLS
- Front Lens and Back Lens: Center X, Center Y, Radius, and FOV affect the
  projection for the next job on that tab.
- Back Rotation aligns the back lens to the front lens.
- Seam Feather adjusts the overlap blend width.
- Reset controls reloads the saved default profile.
- Quick controls do not overwrite the saved default profile. Use Calibration
  and Save profile when a correction should be kept for future sessions.

CALIBRATION
1. Open Calibration and load a sample photo or video.
2. Adjust the lens controls; both previews update automatically as you move a
   slider, so you can inspect the seam immediately.
3. Select Save profile to keep the corrected profile for later sessions.
4. The preview also includes a normal, perspective-corrected view. Adjust Yaw,
   Pitch, and FOV until you can clearly see the subject, then select Export
   normal view to save it as a regular JPG. This does not replace the full 360
   panorama output.

VIDEO AUDIO
FFmpeg preserves source audio in stitched MP4 output.
1. Close Gear 360 Stitcher and open PowerShell as a normal user.
2. Run:
   winget install --id Gyan.FFmpeg -e --accept-source-agreements --accept-package-agreements
3. Close PowerShell, open a new PowerShell window, and run:
   ffmpeg -version
4. Restart the app. The Stitch Videos tab will show whether FFmpeg is available.

KEYBOARD USE
This version has no app-specific keyboard shortcuts. Standard Windows controls
are available:
- Tab / Shift+Tab: move forward/backward between controls.
- Space: activate the focused button.
- Arrow keys: change a focused file-list selection or calibration/quick-control slider.
- Home / End / Page Up / Page Down: move through a focused file list.
- File and folder dialogs use their normal Windows keyboard controls.
